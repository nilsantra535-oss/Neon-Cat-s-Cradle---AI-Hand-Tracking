# Neon Cat's Cradle - AI Hand Tracking 🖐️✨

An interactive web-based creative coding project built using **p5.js** and **MediaPipe Hands**. It tracks hand movements through your webcam in real-time and weaves beautiful, dynamic cyberpunk neon "Cat's Cradle" string patterns and particle starburst effects between your fingertips.

---

## Features
- 🤖 **Real-time AI Hand Tracking:** Powered by Google MediaPipe Hands API.
- 🎨 **Neon Visuals & Effects:** Dynamic HSB color shifting, pulsing glowing fingertips, and interactive starburst particles when fingertips touch.
- 🪞 **Mirror Viewport:** Seamless camera mirroring for an intuitive user experience.
- ⚡ **Zero Setup Required:** Pure HTML, CSS, and Client-side JavaScript running via CDN dependencies.

---

## Technologies Used
- [p5.js](https://p5js.org/) (Canvas rendering & animation)
- [MediaPipe Hands](https://developers.google.com/mediapipe/solutions/vision/hand_landmarker) (Hand landmark detection)
- HTML5 & CSS3
